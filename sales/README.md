# Sales materials

Klient-vendte artefakter til Lodværket BI Accelerator.

| Fil | Hvad | Bruges til |
|---|---|---|
| `PITCH.md` | One-pager pitch | Kold prospect-email + indledende møde |
| `PRICING.md` | 3 pakker + retainer + AI add-on | Efter discovery, sendes som del af tilbud |
| `SCREENCAST.md` | Manuskript til ~5 min demo | Loom/OBS-optagelse for LinkedIn + cold email |
| `CASE_STUDY_TEMPLATE.md` | Skabelon til post-engagement case | Udfyldes efter hvert engagement, klient-godkendes |

## Brug-flow

```
Kold prospect → send 30-sec teaser screencast + link til PITCH.md
        ↓
Discovery-møde (1 time) → udfyld phase B notes
        ↓
Tilbud → tilpas PRICING.md (vælg pakke) + send proposal.md baseret på PITCH.md
        ↓
Levering → byg via PLAYBOOK.md
        ↓
Post-launch → udfyld CASE_STUDY_TEMPLATE.md → klient-godkend → publicer
```
